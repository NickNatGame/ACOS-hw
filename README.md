# Обедающие философы 3: процессы и неименованные семафоры

Процессная версия второго ДЗ на C11 для Linux/POSIX. Родитель создаёт N дочерних
процессов через `fork`, каждый ребёнок выполняет алгоритм одного философа.
Вилки, FIFO-очередь, состояния и статистика находятся в POSIX shared memory.
Общий неименованный семафор защищает модель и вывод; персональные семафоры
уведомляют философов о старте, выдаче вилок и остановке. Все семафоры создаются
с `pshared=1` внутри общей памяти. Размышление и еда выполняются с реальными
задержками без удержания общего семафора.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build
./bin/philosophers
./bin/philosophers --help
ctest --test-dir build --output-on-failure
./tests/run_examples.sh
```

Нужны CMake 3.16+, компилятор C и Make или Ninja. POSIX-семафоры подключаются через
`Threads::Threads`, shared memory — через `rt`. Сторонних библиотек нет.
Команды выполняются из корня проекта. Сборка находится в `build`, программа -
в `bin/philosophers`, тесты - в `bin/philosophers_tests`.
Чтобы отключить сборку тестов, задайте `-DBUILD_TESTING=OFF` при настройке CMake.

## Параметры

```text
./bin/philosophers [N] [cycles] [think_min] [think_max] [eat_min] [eat_max]
                   [max_wait] [display_delay] [seed] [strategy] [time_limit]
```

Аргументы задаются по порядку. Последние можно не указывать — тогда используются значения по умолчанию.
Числовой аргумент должен содержать только цифры `0`–`9`: знаки `+`/`-`, пробелы,
дроби и посторонние символы запрещены. Ведущие нули допустимы: `002` означает 2.
`-h` и `--help` работают только как единственный аргумент.

| Аргумент | Что задаёт | По дефолту |
|---|---|---:|
| N | Количество философов и вилок, от 2 до 256 | 5 |
| cycles | Сколько раз должен поесть каждый философ, минимум 1 | 3 |
| think_min, think_max | Диапазон времени размышления в миллисекундах | 500, 1500 |
| eat_min, eat_max | Диапазон времени еды в миллисекундах | 400, 1000 |
| max_wait | Максимальное ожидание вилок в миллисекундах | 5000 |
| display_delay | Реальная пауза между моментами событий, 0 — без пауз | 120 |
| seed | Начальное значение генератора случайных чисел | 42 |
| strategy | Способ выдачи вилок, поддерживается только fifo | fifo |
| time_limit | Общий лимит модельного времени, без лимита - 0 | 60000 |

Все числа — от 0 до INT_MAX, с дополнительными ограничениями из таблицы.
Верхняя граница диапазона должна быть не меньше нижней. Размеры массивов и
верхние оценки времени/статистики проверяются на переполнение. Проверка
переполнения консервативна: учитывает все циклы даже при коротком общем лимите.
Предел 256 не позволяет ошибочным аргументом запросить создание тысяч участников.
Даже в этом диапазоне запуск зависит от памяти и доступного числа процессов ОС.
При ошибке `fork` уже созданные дети пробуждаются и собираются через `waitpid`.
Параметры проверяются до открытия лога, создания общей памяти и запуска процессов.
При ошибке программа выводит диагностику в stderr и возвращает код 1.

Например, `./bin/philosophers 257`, `./bin/philosophers ' 5'` и
`./bin/philosophers 5 1abc` завершаются с ошибкой без создания `philosophers.log`.
Если журнал уже существовал, ошибка параметров не изменит его.

Проверки ввода входят в `ctest --test-dir build --output-on-failure`:
29 некорректных строк проверяются в каждой из 10 числовых позиций. Отдельно
проверяются ограничения параметров, стратегия, лишние аргументы, значения на
границах диапазонов и все варианты пропуска последних аргументов.

Быстрый пример с реальными короткими задержками:

```bash
./bin/philosophers 5 3 10 30 20 40 1000 50 42 fifo 5000
```

В отличие от первого задания, длительности больше не являются виртуальными:
`display_delay=0` не ускоряет размышление и еду. Время измеряется через
`CLOCK_MONOTONIC` после создания процессов.
У каждого процесса своя копия `rand()`: родитель вызывает `srand(seed)`, философ
с индексом i — `srand(seed + i)`. Планировщик влияет на порядок действий и выдачу
вилок, поэтому seed не фиксирует весь журнал.

## Взаимодействие и завершение

Философ `i` использует вилки `i` и `(i + 1) % N`. Голодный философ добавляется
в FIFO. Арбитр под общим семафором выдаёт первому в очереди сразу обе свободные вилки
и вызывает `sem_post` его персонального семафора. Если хотя бы одна вилка занята,
остальные заявки не обходят первую. Несоседние философы могут есть одновременно.
Философ, ожидающий вилок, спит в `sem_timedwait` и не удерживает общий семафор.

Все события выводятся сразу: размышление, голод, запрос каждой вилки, получение,
еда и освобождение. `display_delay` задаёт только период дополнительных снимков
состояний и владельцев вилок. Родитель проверяет остановку с паузой 5 ms,
работающие философы также проверяют лимиты между действиями и во время задержек.
Ровно `max_wait` допустимо, превышение приводит к остановке до выдачи вилок.
Если достигнут `time_limit` и осталась незавершённая работа, программа останавливается.

Ctrl+C и SIGTERM устанавливают флаг в том процессе, который получил сигнал.
При остановке программа будит все персональные семафоры, выполняет `waitpid`,
освобождает вилки и сохраняет статистику. Сигнал можно отправить родителю или
всей группе процессов; Ctrl+C в терминале действует на всю foreground-группу.
Прерванная еда не засчитывается как завершённый цикл. Ожидание, после которого
еда не началась, учитывается отдельно. `time_limit=0` сохраняет число циклов,
контроль `max_wait` и возможность прерывания сигналом.

| Код | Причина |
|---:|---|
| 0 | Все циклы выполнены или показана справка |
| 1 | Ошибка параметров, shared memory, fork/семафоров, дочернего процесса или ввода-вывода |
| 2 | Превышено ожидание либо достигнут общий лимит |
| 130 | SIGINT, обычно Ctrl+C |
| 143 | SIGTERM |

## Общая память и аварийное завершение

Родитель создаёт объект `/philosophers-PID` через `shm_open` с `O_EXCL` и правами
0600. Сразу выполняется `shm_unlink`: имя удаляется, а объект существует, пока
открыт его дескриптор или сохраняется отображение. Место резервируется через
`posix_fallocate`, затем создаётся `mmap` с `MAP_SHARED`. После отображения
дескриптор закрывается. Резервирование позволяет обработать нехватку места
в `/dev/shm` до записи в отображённую память.

Все данные помещаются в один блок с массивами на `MAX_PHILOSOPHERS`; используются
первые N элементов. В общей структуре нет указателей на локальную память.
После `fork` каждый ребёнок наследует отображение. Только родитель уничтожает
инициализированные семафоры и вызывает `munmap`, когда все дети уже собраны.
При частичной инициализации уничтожаются только успешно созданные семафоры.

Родитель проверяет детей через `waitpid(WNOHANG | WUNTRACED)`. Неожиданный выход
с ошибкой, гибель от сигнала или остановка ребёнка вызывают аварийное завершение
всего запуска с кодом 1. Ожидания общего семафора ограничены интервалами 10 ms:
родитель продолжает проверять детей, даже если погибший участник удерживал его.

При аварии родитель отправляет оставшимся детям SIGTERM, не ожидая общий семафор.
Если дети не завершились примерно за секунду, используется SIGKILL, затем
обязательный `waitpid`. Только после этого родитель приводит вилки в свободное
состояние и печатает итоги. При гибели посередине изменения модели статистика
может быть неполной; это аварийный исход, а не успешно выполненный цикл.
Ошибки stdout и лога дают код 1; закрытый pipe не завершает программу через SIGPIPE.

## Проверки

CTest запускает 31 тестовую функцию. Кроме ввода и анализа FIFO/вилок по журналу,
проверяются реальные дочерние процессы, параллельная еда несоседей, сигналы
родителю и всей группе, SIGKILL/SIGSTOP отдельному ребёнку и повторные запуски.
После запусков проверяется отсутствие объявленных PID и имени общей памяти.

`tests/faults.c` подключается только к отдельной программе `philosophers_faults`
через подмены линкера `--wrap`. Автоматически воспроизводятся 12 сценариев:
отказы `shm_open`, резервирования памяти, `mmap`, общего и персонального семафоров,
частичный отказ `fork`, ошибка часов, ожидания и выдачи семафора, гибель и остановка
ребёнка с занятым общим семафором, SIGINT во время создания детей. Обычная
`philosophers` не содержит этих подмен и не читает тестовую переменную окружения.

Полный запуск вручную:

```bash
./bin/philosophers_tests ./bin/philosophers ./bin/philosophers_faults
```

Без последнего аргумента выполняются 30 функций без подмен системных вызовов.

## Что где лежит

- `src/philosophers.c` - запуск программы.
- `src/parameters.c` - чтение аргументов и справка.
- `src/simulation.c` - общая память, философы, вилки, очередь и контроль детей.
- `src/console.c` - вывод, лог, сигналы и паузы.
- `inc/` - заголовочные файлы.
- `tests/` - тесты и примеры вывода.
- `tests/faults.c` - подмены системных вызовов для проверки аварийных исходов.
- `REPORT_2.md` - исторический отчёт по многопоточному второму ДЗ.
- `build/` - файлы сборки, `bin/` - программа и тесты.
