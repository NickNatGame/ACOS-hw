# Обедающие философы, вариант 5

Последовательная событийная модель на C для Linux/POSIX. Философы представлены
структурами в одном процессе.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build
./bin/philosophers
./bin/philosophers --help
ctest --test-dir build --output-on-failure
```

Для сборки нужны CMake 3.16 или новее, компилятор C и средство сборки
(например, Make или Ninja). Тесты тоже написаны на C, Python не нужен.
Файлы сборки находятся в `build`, программа - в `bin/philosophers`,
тесты — в `bin/philosophers_tests`.
Все команды ниже выполняются из корня проекта.

Если тесты не нужны, их сборку можно отключить:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build build
```

Чтобы снова включить тесты, настройте тот же каталог с `-DBUILD_TESTING=ON`.

## Параметры

```text
./bin/philosophers [N] [cycles] [think_min] [think_max] [eat_min] [eat_max]
               [max_wait] [display_delay] [seed] [strategy] [time_limit]
```

Аргументы необязательны, но задаются по порядку. Пропущенные справа получают
значения по умолчанию. Первые девять аргументов сохранили прежний порядок.

| Параметр | Значение по умолчанию | Значение и ограничения |
|---|---:|---|
| N | 5 | Философов и вилок поровну, N ≥ 2; массивы выделяются по N |
| cycles | 3 | Завершённых приёмов пищи на философа, от 1 до INT_MAX |
| think_min / think_max | 500 / 1500 | Диапазон размышления, от 0 до INT_MAX ms |
| eat_min / eat_max | 400 / 1000 | Диапазон еды, от 1 до INT_MAX ms |
| max_wait | 5000 | Допустимое ожидание, от 1 до INT_MAX ms |
| display_delay | 120 | Реальная пауза между моментами событий, от 0 до INT_MAX ms |
| seed | 42 | Начальное значение генератора, от 0 до INT_MAX |
| strategy | fifo | Поддерживается одна стратегия — арбитр с FIFO |
| time_limit | 60000 | Общий лимит модельного времени, от 0 до INT_MAX ms; 0 отключает |

Верхняя граница каждого диапазона должна быть не меньше нижней.
Все входные числа должны помещаться в int (на данной платформе INT_MAX = 2147483647).
Пределы в 100 философов и миллион циклов/ms убраны. Память выделяется через
calloc/malloc по N и освобождается через free при завершении и ошибках.
Размеры массивов проверяются на переполнение size_t; сочетания параметров,
которые могут переполнить время или статистику long long, отклоняются заранее.
Эта проверка использует верхнюю оценку полного выполнения всех циклов,
даже если пользователь задал короткий общий лимит времени.

Для быстрого запуска без реальных пауз:

```bash
./bin/philosophers 5 3 500 1500 400 1000 5000 0 42
```

Для явного выбора стратегии и общего лимита:

```bash
./bin/philosophers 5 3 500 1500 400 1000 5000 0 42 fifo 60000
```

`max_wait` и `time_limit` относятся к модельному времени. `display_delay` влияет
только на скорость показа. Время переходит к ближайшему событию без округления
до 100 ms. Ровно `max_wait` допустимо; превышение фиксируется на следующей
целой миллисекунде. Если все циклы закончились ровно в `time_limit`, запуск успешен.

Вывод дублируется в `philosophers.log` в текущем каталоге. Каждый запуск
перезаписывает этот файл. Ctrl+C и SIGTERM завершают модель с итогами
и освобождением вилок. При ошибке записи программа сообщает о ней в stderr.

| Код завершения | Причина |
|---:|---|
| 0 | Все циклы выполнены или выведена справка |
| 1 | Некорректные параметры, ошибка открытия/записи/закрытия |
| 2 | Превышено ожидание или достигнут общий лимит |
| 130 | SIGINT, обычно Ctrl+C |
| 143 | SIGTERM |

## Файлы

```text
src/         исходники C
inc/         заголовки с интерфейсами
bin/         готовая программа и тесты
build/       файлы сборки CMake
tests/       проверки и примеры вывода
```

- `CMakeLists.txt` — сборка программы и подключение тестов через CTest.

- `src/philosophers.c` — короткий main.
- `inc/philosophers.h` — параметры и интерфейс программы.
- `src/parameters.c` — справка и проверка аргументов.
- `src/simulation.c` — состояния, очередь, вилки, время и статистика.
- `inc/soft_assert.h` — проверки ошибок с выводом файла, строки и условия.
- `inc/console.h`, `src/console.c` — вывод через дескрипторы, сигналы и пауза.
- `tests/test_philosophers.c` — 22 функции с проверками через Soft Assert.
- `tests/normal.log`, `tests/wait_timeout.log`, `tests/time_limit.log` — результаты запусков.
- `REPORT.md` — проверка исходного решения, соответствие требованиям и отчёт.

Тесты можно запустить через CTest или напрямую:

```bash
./bin/philosophers_tests ./bin/philosophers
```

В тестах общий счётчик `fl_err`, макросы `SOFT_ASSERT_ERR` и
`SOFT_ASSERT_EQ_ERR`, отдельная функция на каждый сценарий и вызовы из `main`.
При успехе выводится `OK: all 22 tests passed`, при ошибках — `FAILED`.
Каждый запуск программы выполняется в отдельном временном каталоге.
Тесты восстанавливают владельцев вилок и очередь по сообщениям, проверяют
FIFO, длительности, лимиты, очистку ресурсов модели и итоговую статистику.

ФИО и группу нужно заполнить в `REPORT.md`. Официальное условие проверено
по `i-tasks.pdf`, страницы 14–15; аннотация на странице 2 допускает выбранную
последовательную модель. Технические требования и критерии оценки PDF выносит
в отдельные документы. Общие требования первого этапа пока доступны в тексте
`chat_philosophers_for_codex.md`.
