## Условие задачи
Официальное условие находится в `i-tasks.pdf`, вариант 5 находится на
страницах 14–15.

Несколько философов сидят за круглым столом. Каждый чередует размышление и еду.
Между соседями лежит вилка; для еды нужны обе соседние вилки. После еды они
освобождаются. Алгоритм одинаков для всех философов. Требуется исключить
взаимную блокировку и контролировать неограниченное ожидание.

Входные данные: количество философов и вилок, число циклов, диапазоны длительности
размышления и еды, стратегия получения вилок и максимальное ожидание.

Вывод: размышление, голод, запрос и получение каждой вилки, еда, освобождение
вилок, продолжительность ожидания. 
Завершение: все циклы либо установленный лимит времени с диагностикой. В режиме без ограничения времени предусмотрено
прерывание пользователем. Каждый философ — самостоятельный равноправный
участник.

## Сверка с официальной методичкой

| Требование | Где и как выполнено |
|---|---|
| Последовательная событийная имитация | Один процесс, структура на каждого философа, переходы состояний в src/simulation.c |
| Чередование размышления и еды | start_thinking, finish_thinking, give_forks, finish_meals |

| Исключение deadlock и контроль голодания | Голодные не держат вилки, строгая очередь, конечная еда, проверка max_wait |
| Количество философов и вилок | Общий N задаёт оба количества, которые равнгы из за того, что философы сидят за круглым столом |

## Сценарий и взаимодействие

Программа выполняется в одном процессе, последовательно.
Философы - элементы массива структур, вилки - массив владельцев,
запросы - массив индексов голодных философов (те самописная очередь).

Каждый философ проходит THINKING → HUNGRY → EATING → THINKING.
После последнего законченного приёма пищи он переходит в DONE.
При досрочном завершении незаконченные философы переходят в STOPPED.

Вилка `i` принадлежит либо одному философу, либо никому (`-1`). Философу `i`
нужны вилки `i` и `(i + 1) % N`. Индексы в программе начинаются с 0,
на экране номера начинаются с 1. Число вилок равно N по устройству круга.

Когда философ проголодался, его индекс добавляется в конец очереди.
Если обе вилки свободны, мы выдаём пару и удаляем
заявку голодного философа. Если занята хотя бы одна, обслуживание останавливается до следующего
события. После еды обе вилки освобождаются. Цикл засчитывается только после
полного окончания еды. Внутри одного момента сначала заканчивается
еда, затем размышление, затем проверяются лимиты и выдаются вилки.
Одновременные заявки упорядочиваются по индексу философа.

## Почему соблюдаются инварианты

| Инвариант | Обоснование |
|---|---|
| Вилкой пользуется не более одного философа | Обе записи владельцев меняются только после проверки, что обе вилки свободны |
| Еда возможна только с двумя соседними вилками | EATING устанавливается после назначения пары |
| После попытки никто не удерживает одну вилку | Отказ не меняет владельцев, успешная попытка выдаёт пару |
| Взаимной блокировки нет | Голодные не владеют вилками |
| Закончивший философ освобождает ресурсы | release_forks вызывается до DONE, при остановке освобождаются вилки каждого EATING |

Строгая очередь (те FIFO) исключает бесконечное вытеснение заявки новыми заявками.
У первого в очереди занятые вилки могут принадлежать только уже едящим,
которые закончат не позднее чем через eat_max. После их освобождения никто
позади очереди не может забрать эту пару раньше него. Перед любой заявкой
не более N−1 других заявок, и новые добавляются сзади.
Значит, в самой модели нет бесконечного голодания, слишком долгую, но конечную
очередь дополнительно останавливает max_wait.

Свободные вилки иногда простаивают, пока первый ждёт, но это разрешено по условию, тк Алгоритм один для всех.

## Пользовательский интерфейс и завершение

Параметры задаются позиционными аргументами командной строки. Часть аргументов
можно опустить справа. Без аргументов используются значения по умолчанию.
`--help` и `-h` выводят справку. Допустимые диапазоны перечислены в README.md.
Поддерживается одна стратегия, задаваемая именем `fifo`, те очередь.

События содержат время и номер философа. После обработки момента
показываются все состояния и владельцы всех вилок. Для голодных показывается
текущая длительность ожидания. Для наглядности есть реальная пауза display_delay.
max_wait включителен: ровно max_wait допустимо, больше - остановка.
time_limit ограничивает общее модельное время и может быть отключён значением 0.
В этом режиме число циклов по-прежнему задано, а ограничение ожидания max_wait
остаётся включённым, отключение общего лимита не отменяет контроль голодания.
Полное завершение всех циклов ровно на общей границе считается успехом.
При ошибке входных данных моделирование не начинается.
SIGINT и SIGTERM устанавливают флаг. Основной код завершает модель,
освобождает вилки и печатает статистику. Начатый, но прерванный прием пищи не считается
завершённым циклом. Ожидание без получения вилок учитывается отдельно.
Среднее рассчитывается по начатым приёмам пищи, тк именно для них
известна полная длительность ожидания до выдачи вилок.
Вывод производится через dprintf/vdprintf и файловые дескрипторы stdout/stderr/лога.
События и итоги сохраняются в philosophers.log, который перезаписывается при следующем запуске.

## Проверенные результаты

Сборка через CMake, запуск из корня проекта:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

Исходники находятся в `src`, заголовки - в `inc`, программа - в `bin`.
CTest запускает bin/philosophers_tests, 22 тестовые функции на C.
Тесты я оформил по примеру предыдущих проектов, еще со времен C.

Пример нормальной работы:

```bash
./bin/philosophers 2 1 3 3 7 7 7 0 42
```

Оба философа размышляют 3 ms. Первый ест с t=3 до t=10, второй с t=10
до t=17. 
Выполнено 2 приёма пищи, ожидания 0 и 7 ms, среднее 3.50 ms.
Код 0. Все вилки свободны.

Превышение ожидания:

```bash
./bin/philosophers 2 1 0 0 200 200 150 0 42
```

Остановка точно в t=151. Второй философ ждал 151 ms при лимите 150 ms
и не получил вилки. Еда первого прервана, цикл не засчитан. Итог:
0 завершённых приёмов пищи, все вилки свободны, код 2.

Общий лимит:

```bash
./bin/philosophers 2 1 0 0 200 200 1000 0 42 fifo 50
```

Остановка точно в t=50. Еда первого прервана, второй ждал 50 ms.
Все вилки свободны, код 2..
